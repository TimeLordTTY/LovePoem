## 一键启动本地联调

在 `poemapp` 目录打开 PowerShell，执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start-all.ps1
```

启动完成后：

- 情晓录网页版：`http://127.0.0.1:3002/`
- LovePoem 网页：`http://127.0.0.1:3010/`
- LovePoem 后台接口：`http://127.0.0.1:8080/api`
- MySQL：`127.0.0.1:9009`

## 构建全部项目

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build-all.ps1
```

构建内容包括情晓录网页版、情晓录 Android 页面资源、Android 调试 APK、LovePoem Java 后台和 LovePoem Vue 前台。

APK 输出位置：

`outputs\qingxiaolu-debug.apk`

## 安装到安卓手机

先在手机中开启“开发者选项”和“USB 调试”，通过数据线连接电脑，然后执行：

```powershell
C:\Users\houyx\AppData\Local\Android\Sdk\platform-tools\adb.exe devices
C:\Users\houyx\AppData\Local\Android\Sdk\platform-tools\adb.exe install -r .\outputs\qingxiaolu-debug.apk
```

也可以把 APK 发送到手机，在手机上点击安装。

## 两种界面的关系

- 网页版是电脑端正式入口，负责长文写作、资料管理、批量导入导出和网站上传。
- Android App 是手机正式入口，使用打包在 APK 内的页面资源，并可逐步连接文件、相册、系统分享等手机权限。
- 两端最终共用同一套项目、文章、历史和同步接口。
- 当前 APK 已可安装并浏览现有原型；数据保存、手机权限和 LovePoem 上传仍需继续连接真实业务接口。
