# 情晓录电脑助手

解压到固定位置，安装 Node.js 22.13 或更高版本，双击「启动情晓录.cmd」。首次选择一个情晓录总文件夹，以后复用；不会随 Windows 自动启动，也不会后台同步。

本地工作台地址固定为 http://127.0.0.1:43127/qingxiaolu/ 。它与线上网页的浏览器存储不同：原网页未同步的内容，请先下载完整备份，在本地工作台的设置中恢复；需要跨设备的记录仍要主动选择云端同步。

- 项目首页可选择文件或拖入，识别后预览并确认导入。
- 「导出」内有双向文件同步。先预览新增、修改、冲突及具体条目，再确认执行；本地修改未读回时不会被 App 覆盖。
- 编辑器中的「保存并用 WPS 编辑」生成真实 DOCX（含全部附图）并请求 WPS 打开。「读回 WPS 文件」解析保存后的同一文件，先对照后确认；原记录保留版本，不自动上传。
- Word 文件放在对应项目的「Word编辑」子目录，以记录 ID 命名，改标题仍读写同一文件。该目录通过编辑器手动读回，不混入 Markdown 的项目文件同步。
- 没有安装或识别到 WPS 时仍保留生成的 DOCX，可自行打开。WPS 安装在非标准位置时，可在 PowerShell 启动脚本时传入 `-WpsPath "实际的 wps.exe 路径"`。
- 双击「停止情晓录.cmd」停止本机服务；不会清除内容。更换总文件夹时先停止，再用启动脚本的 `-RootDirectory "新路径"` 参数启动。

助手只监听本机回环地址；文件操作限制在所选目录并校验页面会话。账号仍使用现有情晓录云端登录，不把账号、密码或令牌写进助手设置文件。私密内容仅在作者手动同步到本地时写入所选文件夹，请按个人资料管理该目录。

已验证文件与浏览器流程、DOCX 图文往返；真实 WPS 客户端的打开和另存行为需要在安装 WPS 的电脑验收。
