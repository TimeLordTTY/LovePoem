情晓录 · 电脑写作

把写作与本地文件接起来

选择一次总文件夹，按项目整理；在 WPS 编辑后，先对照，再手动读回。

下载电脑助手

Windows · 需要 Node.js 22.13 或更高版本；本次开发电脑已具备运行环境。WPS 可单独安装。

开始使用

  1. 解压到固定位置，双击「启动情晓录.cmd」，首次选择情晓录总文件夹。
  2. 在打开的本地工作台写作。项目首页可选择文件或拖入，先预览，再确认导入。
  3. 项目的「导出」页可双向同步文件；确认前查看新增、修改和冲突。
  4. 编辑器里点击「保存并用 WPS 编辑」。WPS 保存后，点击「读回 WPS 文件」，核对正文及图片后确认。
  5. 不用时运行「停止情晓录.cmd」。这会停止本机服务，内容仍保留。

先迁移原网页里的本机内容

本地工作台与线上网页使用不同的浏览器存储。尚未同步的记录不会因登录自动出现：请先在原网页「设置」下载完整备份，再到本地工作台恢复；已选择云端同步的记录可以连接同一账户读取。

请保留原网页数据，确认迁移完整后再自行决定如何管理。

手动确认，保留原文

助手不会自动启动、后台同步或替你发布。Word 文件保存在项目的「Word编辑」目录；Markdown 项目文件有独立的同步预览。文件被外部修改后会拒绝直接覆盖，读回后原记录保留版本。

没有找到 WPS 时，生成的 DOCX 仍在总文件夹，可自行打开。真实 WPS 客户端的打开与保存行为仍需要在安装 WPS 的电脑验证；网页不具备直接启动本地应用的权限。

一次性微博与 QQ 空间采集

电脑助手内含「采集微博.cmd」和「采集QQ空间.cmd」。打开工具，在专用 Edge 窗口登录并进入自己的历史内容页面，按提示开始采集；生成的 JSON 放在系统下载目录，再到情晓录「设置 → 历史导入」选择文件。

工具只读取已经载入的内容卡片，不替你登录、发布或读取未载入的内容。纯图片记录保留；缺日期或疑似折叠的正文会在导入预览中提示补全。真实平台登录后的页面结构尚待现场验收，若识别不到内容，请保留原页面和文件，不把空结果当成成功。
