# 情晓录 ChatGPT 讨论同步助手

这是电脑浏览器辅助同步工具。它只在你点击按钮时读取当前已经打开的 ChatGPT 讨论，不读取账号密码，不在后台抓取其他对话。

## 安装

1. 下载并解压情晓录“设置 → 电脑讨论同步助手”中的扩展包，再打开 Chrome 或 Edge 的扩展管理页。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择解压后包含 `manifest.json` 的文件夹。源码开发时先在情晓录根目录运行 `node scripts/build-discussion-extension.mjs`，再选择生成的 `discussion-extension-dist`，不要直接加载源码文件夹。
5. 将“情晓录 · ChatGPT 讨论同步”固定到浏览器工具栏。

## 使用

1. 在浏览器中登录 ChatGPT，并进入需要同步的讨论。
2. 点击浏览器工具栏中的情晓录扩展。
3. 首次使用以 Poem 账户登录；扩展只保存服务器令牌，不保存密码。
4. 选择情晓录项目和保存位置。
5. 点击“预览”，确认后点击“确认同步”。
6. 回到情晓录网页或 App，点击“同步”。

## 范围

- 当前版本同步当前页面已加载的文字消息。
- 图片、附件、分支讨论以及尚未滚动加载的旧消息暂不采集。
- 这是本地辅助同步，不是 OpenAI 官方 ChatGPT 项目接口。
- 未完成内容暂存在扩展本机，重新打开后可继续。若只有讨论记录成功、项目资料冲突，会分别提示；刷新项目后再次确认，只补充未完成部分。已保存记录不会因重试重复创建。
- 取消未完成操作不删除已经保存的云端内容。不同登录状态的未完成内容分开保留；扩展不保存密码。
- 大正文与项目资料使用情晓录现有分块协议，图片仍由已有项目保留，不会因整理讨论而压缩。等待服务超过单个请求期限会保留待确认内容。
