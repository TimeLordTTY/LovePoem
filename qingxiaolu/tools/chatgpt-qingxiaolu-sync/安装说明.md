# 情晓录 ChatGPT 讨论同步助手

这是电脑浏览器辅助同步工具。它只在你点击按钮时读取当前已经打开的 ChatGPT 讨论，不读取账号密码，不在后台抓取其他对话。

## 安装

1. 打开 Chrome 或 Edge 的扩展管理页。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本文件夹 `chatgpt-qingxiaolu-sync`。
5. 将“情晓录 · ChatGPT 讨论同步”固定到浏览器工具栏。

## 使用

1. 在浏览器中登录 ChatGPT，并进入需要同步的讨论。
2. 点击浏览器工具栏中的情晓录扩展。
3. 首次使用以 Poem 账户登录；扩展只保存服务器令牌，不保存密码。
4. 选择情晓录项目和保存位置。
5. 点击“预览”，确认后点击“确认同步”。
6. 回到情晓录网页或 App，点击“同步”。

## 范围

- 当前版本同步当前页面已加载的文字消息。
- 图片、附件、分支讨论以及尚未滚动加载的旧消息暂不采集。
- 这是本地辅助同步，不是 OpenAI 官方 ChatGPT 项目接口。
