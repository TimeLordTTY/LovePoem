# 情晓录创作体验优化

2026-10-01。开发与部署范围为 `qingxiaolu/` 作者写作端。

## 使用变化

- 首次进入可选择“先在本机使用”，此选择会记住。正文和项目资料自动保存到本机；保存失败会明确提示，正文编辑页可直接下载包含当前编辑内容的备份。
- 正文保存后留在编辑页；刷新恢复标题、正文、图片、标签、所属项目、章节和编辑位置。支持 Ctrl/Cmd+S 保存、新稿件、专注写作、正文查找、基础 Markdown 预览及项目资料侧栏。
- “博客”更名为“稿件库”，增加项目与状态筛选，搜索包含标签，长文可展开。显示仅本机、等待同步、云端已保存或版本冲突。
- 项目“继续写作”打开最近稿件；支持从大纲写本章正文、调整章节顺序，正文按章节排列。非小说项目使用较简洁的资料导航。
- 本机稿件不再按 500 条截断，回收站和本地隐藏记录也不再按条数丢弃。浏览器存储仍有容量限制，失败时不显示保存成功，应及时下载完整备份。
- 云端读取结果缓存到本机，断网后保留已缓存的稿件。手动同步队列只保留每篇最新待同步内容，超过 500 条分批发送，避免并行提交同一队列。同步在途继续改稿时保留新文字。
- 冲突界面可对照本机版和云端版，并选择保留双方、保留本机或使用云端。本机副本不会自动上传；选择云端时本机旧文字仍进入版本记录。
- 完整备份包含正文、项目资料、图片、版本、回收站和当前编辑草稿，不含账号令牌或 AI 密钥。恢复前展示数量，相同 ID 保留本机现有稿件，恢复内容不自动上传。
- 项目全文 Word/Markdown 包含真实正文；Word 是文字导出，不替代含图片的完整 JSON 备份。远程图片不可读取时明确拒绝生成不完整备份。
- 手动文件夹导出附带完整备份，结构化 Markdown 保留章节 ID。读回时保留章节关联及备份中的图片；写入与读回前均确认范围。
