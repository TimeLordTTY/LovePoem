# 项目思维树：开发与验收

日期：2026-10-15。对应原设计《思维树适配方案-20261015》。本文件记录新增功能与本次验收，不替代原系统尚缺真实客户端接入的验收清单。

## 使用入口与范围

进入项目 →「思维树」或项目首页「整理思维树」。小说、诗歌、随笔日记等项目均可使用，一个项目允许多张树。

- 新建、重命名与删除树；自由文字、长备注；子节点、同级节点、调整父节点与顺序、分支折叠。
- 自动布局的图形画布与层级列表；平移、缩放、适配全图、搜索定位、全屏整理和选中节点编辑。
- 桌面拖动节点到另一节点下；手机也可选择目标父节点后移动，无须依赖精细拖动。键盘撤销／重做仅在画布操作范围内生效，输入法组合事件不触发新增。
- 引用本项目文章、灵感、人物、章节、时间轴事件或整段项目资料；改名跟随原内容，允许独立别名；失效引用保留节点并提示。打开原内容前保存项目；原有正文列表和统计仍只使用原来的正文数据。
- 当前会话撤销／重做；删除前确认范围，并可靠保留一份项目版本。保存恢复版本失败时不删除。切换到其他资料后，可从「项目 → 项目版本」恢复，不承诺内存撤销栈跨 App 重启保留。
- 独立导图 JSON 预览、导入和导出，以及现有项目完整备份／恢复。复制导入分配新树与节点 ID；跨项目解除引用并提示重新关联，不按同名猜测目标。

本机优先保存。作者仍通过原有项目开关选择是否同步，不因创建导图自动上传。删除树或节点不删除原文、人物等目标对象。云端冲突粒度仍为整个项目，不做逐节点自动合并。

第一版采用自动布局，拖动用于换父节点，排序按钮用于同级调整；不是自由坐标排版。横向关系线、图片节点、AI 自动生成和图像导出尚未开放。

## 数据和保护

- `ProjectWorkspaceData.mindTrees` 可选字段，旧项目无字段可继续使用。网页／Android／电脑助手共用 React 组件和结构。
- `mobile/mindTree.ts`：稳定身份、不可变节点操作、无递归布局、导入复制。
- `sync-server/mind-tree-schema.mjs`：前后端共用结构校验；同步服务只解码导图字段，不把大量原图整体解码进内存。
- 校验重复 ID、根节点、无效父节点、不可达节点及父子环路。不存在的内容引用不会导致整树丢弃。
- 服务端拒绝旧客户端缺少已有导图字段的项目覆盖，并给出更新／读取最新内容提示。旧版本用户应先更新，不清空旧 App 数据。
- 每树上限 2000 节点，每项目 100 张树，项目树 JSON 上限 800 万字符；节点文字 2000 字符、备注 10 万字符。独立文件导入上限 32MB，为大段中文的合法导出保留往返空间。这些是保护上限，不代表所有低端手机在上限下均流畅。
- 缩放和平移不生成作品云端版本。节点选择仅缓存当前设备的会话视图，不携带原文或凭据。

## 本次实际修复的操作问题

1. 旧资料选段菜单会在安卓导图输入时出现并遮挡按钮：导图使用自己的操作面板，原资料选段保留。
2. 全屏时返回键可能直接离开项目：项目统一分派返回动作，先退出全屏。
3. 删除或移动后同级顺序有空位，新节点可能插入错误位置：规范化顺序，新增追加到末尾。
4. 保存成功提示可能覆盖文件夹同步结果：自动保存前检查是否仍有未保存变化。
5. 双指操作从节点开始不能只按背景拖动处理：跟踪触摸节点，单指点击仍可选择，双指统一计算缩放。

- `tests/mind-tree-live.mjs --live-author-acceptance`：真实 HTTPS 的普通和长备注分块同步、旧客户端字段丢失拒绝、父子环路拒绝、陈旧版本冲突、独立浏览器读取。仅生成临时项目，结束删除临时项目并核对其他云端记录哈希不变；凭据仅在内存中。
- 受影响 TypeScript、正式／验收 APK 构建和签名／资源一致性检查。
- 既有电脑工作台真实磁盘回归：DOCX 图文读回、外部修改保护、文件夹双向预览与冲突、项目改名；真实 WPS 客户端仍未接入。
