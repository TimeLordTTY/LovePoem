# 网站上传统一登录与重试优化

核对日期：2026-10-02。修改范围限于情晓录。

## 已修复和优化

- “上传网站”沿用当前情晓录会话，移除重复的网站账号、密码和 API 地址表单。现有有效会话可以直接进入上传页，只有主会话失效时才回到情晓录登录。
- 复现了网站后台对页面来源返回 `403 Invalid CORS request`。情晓录上传通道在服务端转接固定网站接口，返回规范 JSON 和可理解的错误信息，不调整网站原后台或全局 CORS。
- 上传始终保存为网站 `PRIVATE + DRAFT`。重复上传更新当前作者的私密草稿；已经公开的作品另建私密草稿，保留其原内容和地址。上传接口不开放发布、任意代理或修改其他作者作品。
- 使用原情晓录稿件标识查找对应网站草稿，网络中断或本机上传映射缺失后重试可找回已创建的草稿。没有新增数据库表。
- 同一账户、相同标题和相同图片的短时间重试复用已确认资源。复用前核对图片记录未删除，缓存最多 200 条且有效期 10 分钟；不同标题沿用原有图片库标题行为。
- 连续点击不会并行上传同一稿件。上传期间固定当前稿件、文章类型和系列，避免界面选择与正在上传的内容不一致。
- 网站确认成功后，本机上传记录写入失败会明确提示“网站已保存、本机记录未写入”，不误报上传失败；本次页面内仍保留对应草稿 ID。
- 图片文件名按真实类型保存，保留 PNG、JPEG、SVG、WebP 等格式。异常图片、空响应和主会话失效不会再产生原始 JSON 解析错误。
- 完整备份文件名改用本机当天日期，解决凌晨 UTC 日期落在前一天的问题；备份内容和恢复格式不变。

## 认证与功能边界

沿用既有单作者 `SYNC_AUTH_USER` 登录约束，由服务器核对同一有效账户，并在服务器内使用短期网站认证凭证。认证配置只保存在服务器受限配置文件中，不返回浏览器或进入 Git。

现有写作、逐篇勾选同步、私密稿隔离、草稿上传、离线缓存和备份恢复功能保留。此次不替换 LovePoem 的前后端、Nginx 配置或服务器原 APK。服务器的建表脚本早于交接源码，预验收与正式服务都沿用线上现有脚本，不发布建表迁移。
