## 本地数据库与服务

- MySQL 8.4 由已校验的官方安装包提取到 `D:\Project\xiao-poem\poemapp\.local-tools\mysql-extracted/`，没有安装系统服务；实例只监听 `127.0.0.1:9009`，数据在同级 `mysql-data/`。配置为同级 `mysql-local.ini`。
- 重启电脑后，需要时在 PowerShell 启动这个本地实例：

  ```powershell
  $base = 'D:\Project\xiao-poem\poemapp\.local-tools'
  $exe = Join-Path $base 'mysql-extracted\PFiles64\MySQL\MySQL Server 8.4\bin\mysqld.exe'
  $ini = Join-Path $base 'mysql-local.ini'
  Start-Process -FilePath $exe -ArgumentList "--defaults-file=`"$ini`"" -WindowStyle Hidden
  ```

- 数据库 `poem` 已导入 LovePoem 的 `database/schema.sql` 和情晓录的 `sync-server/schema.sql`，共 19 张表，其中 4 张为 `qx_*`。没有导入带固定弱口令的 `database/init_data.sql`；已通过本地注册接口创建独立测试账号，凭据仅在忽略的 `local-test-account.json` 中。
- 本地数据库账号仅在忽略的 `mysql-app-credentials.json` 中；管理员客户端配置仅在忽略的 `mysql-client.cnf` 中。不要复制这些文件到 Git 或服务器。
- LovePoem 后端本地运行时，从本地凭据文件设置 `DB_URL`、`DB_USERNAME`、`DB_PASSWORD`，并将 `server.address` 限制为 `127.0.0.1`。本机 JDK 需要指定项目专用的 `-Djdk.net.unixdomain.tmpdir=D:\Project\xiao-poem\poemapp\.local-tools\java-sockets`，否则 Tomcat 初始化本地套接字失败。此属性无需写入全局 Java 配置。
- 情晓录同步服务在 `sync-server/` 执行 `npm ci` 后，可用 `node --env-file=.env server.mjs` 启动；本地 `.env` 已建立且被 Git 忽略。2026-09-29 已验证本地 LovePoem 注册、情晓录同步登录和空数据拉取链路；正式功能仍需按具体需求单独验收。
- 旧的 `scripts/start-all.ps1`、`scripts/build-all.ps1` 和 `scripts/deploy-server.sh` 含原电脑硬编码路径或旧部署假设；使用前先按当前环境核对，不要直接用于服务器。
